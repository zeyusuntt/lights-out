# Independent Stage 4 audit

Run `./run.sh <stage-folder>`. This one required argument selects the full service folder to build and start. The runner builds the supplied service and documented kit mock, runs the public sample, starts private authored corpora and the accepted legacy Stage1/2/3 services, executes inherited and Stage4 API/browser/crash probes, prints counts and exits nonzero on failure. It removes all containers/networks it starts. No product modules or product/supplied/peer test source are imported.

Services use2vCPU/3GiB. Builds/browser jobs use with-slot; Playwright Chromium runs in df-harness-runner. The mock follows its README and corpus/admin API. A proxy forwards real mock answers and exposes call timing, without synthesizing provider statuses/billing or logging authorization headers. The refund-durability probe alone holds5xx answers for200ms to expose the settlement boundary, still below one second per call. Service state is kept only in each container's writable layer, allowing abrupt docker kill/start tests. Legacy folders are taken from accepted siblings or exact accepted fclone fallbacks if this is a standalone stage folder.

`lineage.py` independently tests normalized publisher/original/lookalike precedence, root-specific Canonical depth and cycles, eight-original fanout, standing versus current origins, member corroboration, investor name grammar/membership/dates/history, batch validation/ownership/idempotency/costs, overlapping writers, tiny and50-domain budgets, research failure, billed units across crashes, native running-batch snapshots and legacy upgrades. `temporal.py` retains the Stage3 temporal/durability cases with the Stage4 eight-field and interrupted-build rules. `browser.py` runs required flows at1280/375 pixels and adds investor/origin markup checks without reusing the six-field IDs.

Optional environment selectors: SECOND_READER_ONLY=case1,case2; SECOND_READER_FIRST=case1,case2; SECOND_READER_NO_BROWSER=1; SECOND_READER_BROWSER_ONLY=case-name-without-browser-prefix. Default runs every probe. A sample-corpus case still runs under selectors. Each invocation prints PROBE_WORK and writes last-results.json; temporary artifacts/results are excluded from publication. Exports and tokens stay in memory; temporary browser configuration is removed.

The probes remain private until every stage closes and fpublish publishes them. A later build can be tested without editing the probes by passing its complete stage folder.
